# implement-slice

Read the bounded handoff and rule before editing. Make the smallest coherent
change in the chosen project. Keep expected fixtures separate from implementation.
Run only checks authorized for the task using the project's normal workflow;
these instructions do not authorize arbitrary commands or external side effects.
Record changed paths, actual commands/results and limitations in a handoff.
Do not claim verification you did not perform, expand scope, self-approve,
merge or publish. Route evidence review to verify-evidence when the slice is ready.
