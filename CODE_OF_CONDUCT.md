# Code of conduct

Be respectful, specific and constructive. Welcome different backgrounds and levels
of experience. Critique work rather than people. Harassment, threats, discriminatory
conduct, doxxing and sharing private information are not acceptable.

These expectations apply to project issues, pull requests and other official
project spaces. The owner may remove harmful content, close threads or restrict
participation when necessary, with a proportionate explanation when appropriate.
For a concern, ask the owner for a private reporting route through a non-sensitive
project issue; do not post personal details publicly. No private contact channel
or response deadline is promised by this document.
