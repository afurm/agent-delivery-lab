# Contributing

Use a fork of the public afurm/agent-delivery-lab repository and a topic
branch in your fork. Open a pull request with a bounded problem, changed behavior,
actual checks and limitations. Do not create contribution branches in the owner's
repository. Never include private code, credentials or real attendee information.

Use Node 22+ with no dependency installation. Run `npm test`, `npm run demo` and
`npm run smoke`. Keep canonical skills in skills/; adapters copy the same bytes.
Preserve intentionally failing demo behavior and separately specified fixtures.
Do not claim live harness testing when only exporter layout checks were run.

Only @afurm approves and performs merges. Independent contributors submit from
fork branches; contributors and agents must not self-approve or enable automatic
merge. Leave owner-authored changes pending rather than treating owner
self-approval as an independent review.

CODEOWNERS expresses owner review responsibility; it does not enforce it.
Effective required reviews, checks, bypass and push restrictions are controlled
in GitHub. Follow the current repository policies; do not skip checks or alter
settings to land a change. Repository files alone do not prove enforcement.
No automatic merge, release, package publishing or approval action is provided.
